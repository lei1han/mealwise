## 3. 关键任务

1. 定义"拳换算"提示词内嵌规则：半拳 0.5×、一拳 1×、两拳 2×、以上 2.5×。
2. 定义区间输出硬格式：`这餐约 {min}~{max} 大卡` + 预算对比；低置信度要诚实标注。
3. 定义记忆抽取的触发与去重（同一信息不重复记忆、更新而非叠加）。
4. 定义毒舌边界词表（禁止表达）与"损完给台阶"的固定结构。

## 4. 依赖与完成标准

- 依赖：契约 A（记忆分类）、契约 B 最终确认、食物库条目名（后端）。
