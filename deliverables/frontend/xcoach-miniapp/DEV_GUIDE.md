# X教练 微信开发者工具导入与调试指南

## 一、环境准备

### 1. 安装微信开发者工具

下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

选择 **稳定版（Stable Build）** 对应你的操作系统安装。

### 2. 注册小程序（如未注册）

1. 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序账号
2. 完成主体信息认证
3. 登录后进入「开发管理」→「开发设置」，获取 **AppID**

> 如果没有 AppID，可使用开发者工具的「测试号」模式，但部分 API（如 `wx.login`、订阅消息）会受限。

---

## 二、导入项目

### 1. 打开开发者工具

启动后，点击左侧 **「小程序」** → 右侧 **「+」创建新项目** 或点击 **「导入项目」**。

### 2. 填写项目信息

| 字段 | 值 |
|---|---|
| 项目名称 | `X教练` |
| 目录 | 选择 `deliverables/frontend/xcoach-miniapp/` |
| AppID | 填入你的小程序 AppID（或选择「测试号」） |
| 开发模式 | 小程序 |
| 后端服务 | 不使用云服务（当前阶段 Mock 数据） |

### 3. 确认导入

点击 **「确定」**，工具会自动编译并打开项目。

---

## 三、项目初始化检查

### 1. 确认编译无报错

项目导入后，底部控制台（Console）应无红色错误。常见问题及处理：

| 问题 | 处理 |
|---|---|
| `app.json 未找到` | 确认导入目录是 `xcoach-miniapp/` 而非上层目录 |
| `未配置 AppID` | 在 `project.config.json` 中填入 `appid` 字段 |
| 页面路径报错 | 检查 `app.json` 的 `pages` 数组是否与 `pages/` 目录一致 |

### 2. 确认模拟器正常显示

上方模拟器应显示 **启动闪屏页**（全屏鼠尾草绿 + "X" 品牌字母）。

如果模拟器白屏，点击工具栏 **「编译」** 按钮重新编译。

---

## 四、调试 Mock 模式

### 4.1 确认 Mock 已启用

打开 `utils/api.js`，确认第一行：

```js
const USE_MOCK = true;
```

### 4.2 走通完整用户旅程

按以下顺序点击/操作，验证页面跳转和交互：

#### 步骤 1：启动闪屏（自动）

- 打开项目后自动显示闪屏
- 1.8 秒后自动跳转至授权登录页
- **验证点**：闪屏动画正常、跳转无卡顿

#### 步骤 2：授权登录

- 点击 **「微信授权登录」** 按钮
- 开发者工具会弹出授权模拟弹窗，点击「允许」
- 自动跳转至摸底定标聊天页
- **验证点**：品牌区、功能引导卡片、协议链接可点击

#### 步骤 3：摸底定标对话

- 教练首条消息："嗨，我是 X教练..."
- 在底部输入框输入 **「好」**，点击发送
- 教练回复："怎么称呼你？"
- 输入昵称（如 **「小雅」**），发送
- 教练回复："身高、现在体重报一下..."
- 输入 **「165 68」**，发送
- 教练回复："减过几次？..."
- 输入 **「两次，上次因为工作忙放弃了」**，发送
- 教练回复："了解。想减到多少？..."
- 输入 **「55」**，发送
- 教练回复定标确认文本 + 三个快速回复按钮
- 点击 **「确认目标」**
- 教练回复确认 + 自动弹出体质信息录入 Sheet
- **验证点**：每轮对话气泡正确、打字动画显示、快速回复 Pill 可点击

#### 步骤 4：体质信息录入

- 底部分 Sheet 弹出
- 选择性别（默认选"女"）、年龄段（默认"25-34"）
- 填写体重、目标体重、身高
- 点击 **「保存」**
- 返回摸底聊天页
- **验证点**：Sheet 弹出动画、表单验证（空值提示）、保存后返回

#### 步骤 5：模拟每日聊天

- 模拟器底部工具栏点击 **「编译模式」** → 选择启动页为 `chat-main`
- 重新编译，进入每日聊天页
- 页面显示带预算卡的欢迎消息
- 输入 **「中午吃了鸡腿饭」**，发送
- 教练回复含热量估算（Mock 数据）
- **验证点**：预算卡三段式展示、进度条、气泡样式

#### 步骤 6：子流程 Sheet

- 点击导航栏 **「毒舌」** → 打开毒舌档位选择
- 点击 **「辛辣」** → 点击 **「确认选择」**
- 点击导航栏 **「通知」** → 打开订阅消息授权
- 点击 **「开启通知」**（模拟器会弹出订阅消息授权模拟）
- **验证点**：Sheet 弹出/关闭、选中态切换、遮罩点击关闭

## 五、常用调试工具

### 5.1 控制台（Console）

底部 **「Console」** 面板查看日志输出：

- `wx.login success` — 静默登录成功
- Mock 数据返回的 `reply_text` 等内容

### 5.2 调试器（Sources）

- 在 `pages/` 下的 `.js` 文件中打断点
- 查看 `this.data.messages` 等运行时数据

### 5.3 AppData

- 底部 **「AppData」** 面板查看当前页面的 `data` 对象
- 可实时修改数据，观察 UI 变化

### 5.4 Storage

- 顶部菜单 **「工具」→「清除缓存」** → 勾选「清除数据缓存」
- 用于重置登录状态，重新走授权流程

### 5.5 编译模式

- 点击工具栏 **「编译模式」** 下拉菜单 → **「添加编译模式」**
- 可指定启动页面、启动参数，方便调试特定页面：

| 调试场景 | 启动页面 |
|---|---|
| 闪屏 | `pages/splash/splash` |
| 授权登录 | `pages/auth-login/auth-login` |
| 摸底对话 | `pages/chat-onboarding/chat-onboarding` |
| 每日聊天 | `pages/chat-main/chat-main` |
| 体质录入 | `pages/sheet-weight/sheet-weight` |
| 毒舌档位 | `pages/sheet-snark/sheet-snark` |
| 订阅消息 | `pages/sheet-subscribe/sheet-subscribe` |

## 六、切换到真实接口

当后端接口就绪后，修改 `utils/api.js`：

```js
// 将 USE_MOCK 改为 false
const USE_MOCK = false;
```

同时在 `project.config.json` 中配置云函数环境（如使用微信云开发），或修改 `utils/api.js` 中的 `callCloudFunction` 为你的实际请求方式（如 `wx.request`）。

## 七、常见问题

### Q: 模拟器白屏，无任何内容？

1. 点击工具栏 **「编译」** 重新编译
2. 检查 `app.json` 中的 `pages` 数组第一项是否为 `pages/splash/splash`
3. 检查控制台是否有报错

### Q: 授权登录弹窗无法弹出？

开发者工具中 `wx.getUserProfile` 的模拟弹窗需要点击模拟器中的按钮才会触发。确保点击了「微信授权登录」按钮。

### Q: 页面跳转后空白？

Sheet 页面（`sheet-weight/snark/subscribe`）使用 `custom` 导航栏，需要从聊天页 `navigateTo` 打开，不能直接作为启动页。

### Q: 如何重置 Mock 数据？

清除 Storage 缓存（顶部菜单「工具」→「清除缓存」→「清除数据缓存」），或者直接重新编译项目。

### Q: 样式不生效？

检查 `app.wxss` 中 CSS 变量是否正确加载。微信小程序中 `rpx` 单位会自动转换，但 CSS 变量中的 `rpx` 值需要带单位。本项目已在 `app.wxss` 中统一使用 `rpx`。
